# dsh-usage-suite

DeepSeek Harness（DSH）桌面端的一个插件，把**用量费用统计**和**提问置顶**两块能力合在一起。

## 一、用量与费用统计

| 位置 | 显示内容 |
|---|---|
| 输入框下方的统计行 | **本轮花费**，如 本轮 ¥0.1234（金额保留四位小数，鼠标悬浮看 token 明细） |
| 侧栏底部「远程控制」上方 | **今日用量**：所有工作区与母会话的 token 合计、消费金额，以及当前属于空闲时段还是高峰时段 |

计费规则（与 DeepSeek 官方一致）：

- 高峰时段：北京时间周一至周五 09:00-12:00、14:00-18:00
- 空闲时段：其余时间，含周末与法定节假日全天；空闲价 = 高峰价的一半
- 缓存写入按「输入（缓存未命中）」计价（官方未单列该价格）
- 计费时段按北京时间判定；「今天」的边界按本机时区的 0 点判定

内置价目表（元 / 百万 tokens，采集自官方定价页）：

| 模型 | 缓存命中（空闲/高峰） | 缓存未命中（空闲/高峰） | 输出（空闲/高峰） |
|---|---|---|---|
| deepseek-flash | 0.02 / 0.04 | 1 / 2 | 4 / 8 |
| deepseek-v4-pro | 0.15 / 0.30 | 4.5 / 9 | 13.5 / 27 |

官方调价后，在「设置 -> 插件 -> dsh-usage-suite」里直接改数字即可。法定节假日由插件自动从公开接口获取（见下一节），也可以在设置项 holidays 里手动补充。

数据口径：

- **今日**：按本机时区的自然日统计，跨所有工作区、所有母会话求和；重启后会重新扫描当天被写过的会话日志来重建，不依赖插件是否一直在运行。
- **子代理会话默认不计入**，可在设置里打开 includeSubagents。
- **本轮**：以轮次开始事件为界，每轮清零。
- 同一步骤的重复上报（重试）以最后一次为准，不会重复计费。

### 法定节假日怎么来的

放假安排由国务院每年公布，程序无法自行推算，因此插件会从公开接口（默认 timor.tech，免费、无需注册）自动获取当年与次年的安排：

- 只取「放假」的日期；周末补班日不进入集合（官方规则里周六周日整体算空闲时段，补班不影响计价）
- 结果按年缓存在 $DSH_HOME/usage-suite/holidays.json，缓存 30 天，避免每次启动都请求
- 取不到时（断网、接口不可用、次年安排尚未公布）自动沿用已有缓存，计价与界面照常工作
- 请求只包含年份，不含任何本机信息；可在设置里把 autoHolidays 关掉改用手动填写，也可用 holidaysApi 换数据源

## 二、提问置顶

- 对话区顶部右侧钉着一个气泡：📌 第 N 轮 · 当前问题 · 点击回到这里，下面是**最新一条提问**（最多两行，超出省略号）。
- 滚动对话时它固定不动；你每发一条新消息它就跟着换。
- **点击**会按可靠性依次尝试：① 点 DSH 自带的「跳转到第 N 轮」按钮（它会加载尚未渲染的历史并精确定位）；② 该轮已在页面上，就平滑滚到它的轮次标记并居中；③ 若目标就是最新一轮且前两条不成立，就滚到对话底部。三条都不成立时气泡上提示「向上滚一点」，不报错也不乱滚。

## 三、插件页里的配置卡片

插件在左侧栏「插件」页的「官方」分组里占一条，标题「用量与置顶」。点进去可以改 18 项设置，分三组折叠：

| 分组 | 内容 |
|---|---|
| 基础设置 | 启用插件、是否把子代理计入今日统计、界面刷新间隔 |
| 法定节假日 | 是否自动获取、数据源地址、手动补充的节假日 |
| 价目表（元 / 百万 tokens） | flash 与 pro 各自的缓存命中/未命中、输入/输出，高峰价与空闲价 |

改完点「保存」写入当前 profile 的配置，立即生效；点「放弃」丢弃本次修改。

## 四、侧栏顶部的桌面按钮

侧栏最上方（logo 下方、「新会话」上方）有两个按钮：

- **重启桌面端**：重启整个 DSH 应用。DSH 还会再弹一次确认框；重启会中断正在运行的任务。
- **重载界面**：只重新加载当前界面，不中断任何任务。

两者都用 DSH 官方的按钮组件。在普通浏览器里打开时（没有桌面端环境），重启按钮会自动禁用。

## 五、插件页「官方」分组的折叠开关

「插件」页「官方」那一行右侧有一个开关，用来收起或展开整组官方插件。开关用的是 DSH 官方的 Switch 组件，样式与行为都跟页面里其它开关一致。

## 设置项

| 键 | 默认值 | 说明 |
|---|---|---|
| enabled | true | 关闭后界面上的统计与置顶都不显示 |
| includeSubagents | false | 是否把子代理会话计入今日统计 |
| pollSeconds | 1 | 界面刷新间隔（0.5 - 30 秒） |
| autoHolidays | true | 自动从网络获取中国法定节假日（只发送年份，不含任何本机信息） |
| holidaysApi | timor.tech | 节假日数据源地址，{year} 会被替换成四位年份 |
| holidays | 空 | 手动补充的节假日（与自动获取的结果合并） |
| flash* / pro* | 见上表 | 两档价格，元 / 百万 tokens |

## 只读接口

宿主半注册一个仅本机可访问的只读接口：

- GET /dsh-usage/state?session=会话id —— 今日累计、当前轮、计费时段
- GET /dsh-usage/health —— 回填是否完成

## 安装

从 GitHub 直接安装：

1. 在 DSH profile 目录执行：pnpm add github:xfpuls/dsh-usage-suite
2. 在该 profile 的 package.json 里把 dsh-usage-suite 加进 dsh.profile.bundles
3. 重启一次桌面端（新增插件条目需要重启；之后改客户端代码会自动热重载）

也可以从插件市场按上面的仓库地址安装。

## 已知限制

- 计费时段按北京时间判定；电脑时区不是 UTC+8 时，界面里的北京时间与本地日期边界会不一致。
- 法定节假日来自公开接口并按年缓存；离线时沿用上次缓存，次年的安排要等官方公布后才能拿到（公布前按普通工作日计算）。
- 置顶气泡会遮住消息区顶部一小块内容，这是「钉住」的必然代价；它的数据来自会话的轮次导航，因此没有消息时间戳与复制按钮。
- DSH 没有为「消息列表上方」预留插槽，所以气泡是固定定位的浮层；若 DSH 之后调整标题栏结构，定位可能需要在设置里微调。
